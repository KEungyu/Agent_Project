# R-1 추가 요청: 대구·대전·광주 여행지와 지하철 지도

확인일: 2026-10-07. 기준 커밋: `a4e8e30`. 사용자가 선택한 3개 도시만 추가했다.

## 반영 내용

| 도시 | 여행지 3곳 | 지하철 |
| --- | --- | --- |
| 대구 | 서문시장, 김광석 다시그리기길, 근대문화골목 | 기존 1·2·3호선 데이터와 지역 선택 유지 |
| 대전 | 한밭수목원, 국립중앙과학관, 성심당 본점 | 1호선 22역·21개 인접 연결 추가 |
| 광주 | 국립아시아문화전당, 대인시장, 충장로 | 1호선 20역·19개 인접 연결 추가 |

여행지 목록은 11개 도시에서 14개로 늘었다. 지도 위치, 도시 선택, 일정의 도시 인식, 도시 색상, 도시별 소개·관광지 설명을 추가했다. 도시 이름과 설명은 기존 9개 화면 언어를 지원하며, 관광지 이름은 기존 방식대로 한국어·영어를 사용한다. 새 관광지 사진은 추가하지 않고 기존 카테고리 아이콘을 사용한다.

새 도시가 도시 간 이동 안내에서도 빠지지 않도록 서울–동대구, 서울–대전, 용산–광주송정, 대전–동대구, 동대구–부산, 대전–부산의 기본 KTX 연결과 코레일 링크를 추가했다. 열차별 소요 시간·요금·좌석은 넣지 않았다. 모든 도시 쌍이 직접 또는 한 도시 경유 안내로 연결되는 기존 검사를 유지했다. 경유 안내는 최적 경로나 실제 연결편 보장을 뜻하지 않는다.

지역 지하철은 기존 부산·대구 화면을 재사용한다. 역 검색, 역 선택 카드, 노선 필터, 확대·축소, 운영기관 링크를 제공한다. 정적 역 연결도이며 지역의 실제 경로·시간·요금·막차 조회는 지원하지 않는다. 이 한계는 화면에도 표시된다. 부산 노선 데이터와 수도권 조회 로직은 이번에 변경하지 않았다.

처음 전체 검사에서 신규 도시의 이동 안내 누락이 발견되었고, 기본 철도 연결을 추가한 뒤 전체 검사를 다시 통과했다. OSM의 대전 월드컵경기장역 번호가 반석역의 `122`와 중복되는 것도 검사로 발견했다. 확인되지 않은 번호는 표시하지 않도록 수집기와 저장 데이터를 함께 수정했다. 월드컵경기장역은 이름으로 검색할 수 있다. 광주 일부 역도 원본에 번호가 없어 이름으로 검색한다.

브라우저 검증은 기존 `localhost:3000` 서버에서 진행했다. 별도 3033 서버는 Next 개발 서버 중복 실행 제한으로 종료되었다. 실제 사용자 요청, 외부 발송, 예약, ODsay 실호출은 수행하지 않았다. 배포 사이트 및 모바일 실기기 검증은 하지 않았다. 번역의 원어민 검토도 별도다.

## 실행 방법

```sh
npm run dev
npm test
npm run build
npm run validate:types
```

`http://localhost:3000`의 여행지 둘러보기에서 추가 도시를 선택한다. 지하철의 지역 선택에서 대전 또는 광주를 고르고 역 이름·번호를 검색한다.

데이터 갱신이 필요할 때만 아래 명령을 사용하고, 갱신 후 역 순서 검사를 다시 실행한다.

```sh
npm run transit:fetch -- daejeon
npm run transit:fetch -- gwangju
```

의존성·DB 스키마 변경 없음. 커밋·푸시·배포는 수행하지 않았다.
