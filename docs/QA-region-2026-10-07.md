# 마중이 최신판 종합 점검 및 지역·티머니 보완

검사일: 2026-10-07 KST. 기준 main: `46cb49f647a4ff5965b815d1797dbbfb9b0d2fde`. 브랜치: `release/r1-demo`.
이 문서는 로컬 검사 결과다. 게시·병합·Render 결과는 PR과 데스크탑 최종 보고서에 별도로 기록한다.

## 판단과 작업 순서

1. 최신 main과 현재 파일을 대조한다. 김은규 님의 부산·대구 노선도 데이터는 아직 이 기준 main에 없다. 이번 사용자 지시로 지역 선택·티머니 안내를 보완하며 기존 단계 R-1 전체 완료를 주장하지 않는다.
2. 표시 지역을 구분한다. 서울·수도권은 기존 지도·역 검색·ODsay 흐름을 사용한다. 부산·대구는 공식 안내로 연결하고 자체 지도·경로·시간·요금은 미제공이라고 명시한다. 지원하지 않는 지역에 수도권 결과를 재사용하지 않는다.
3. 티머니 안내를 기존 지하철 화면의 접이식 도움말에 넣는다. 공항 정보를 입력하지 않은 여행자도 읽을 수 있다. 구매·충전·개찰구 양쪽 태그·잔액·카드별 조건을 설명한다. 기존 공항 팁의 구매·환불 문구도 같은 기준으로 고친다.
4. 지역 전환, 언어 변경, 새로고침, 좁은 화면, 키보드와 자동 검사를 확인한다. 발견된 언어 변경 시 지역 초기화는 이 탭의 `sessionStorage`에 표시 지역만 보관하여 보완한다. 여행 보드·DB 필드는 추가하지 않는다.
5. 게시 직전 main을 다시 가져와 공동 작업을 확인하고 검증된 변경만 병합·배포한다. 운영 요금 조회와 사용자 관찰은 별도 증거가 있어야 완료로 판단한다.

## 변경 파일과 보존한 동작

- `app/components/TransitGuide.tsx`: 지역 선택, 부산·대구 공식 안내, 티머니 도움말. 지역을 떠나면 수도권 패널을 해제하므로 역·경로·출발 확인·조회 결과가 제거된다. 돌아오면 새 입력으로 시작한다. 표시 지역은 언어 변경·새로고침 후 복원하며 브라우저 저장소가 차단돼도 선택 자체는 동작한다.
- `app/globals.css`: 기존 색·필드·링크 스타일을 재사용한 소규모 배치.
- `lib/i18n/messages.ts`: 9개 언어의 고정 문구와 기존 공항 구매·환불 표현 보완. 모든 편의점·교통수단에서 동일하게 된다는 보장, 무제한 패스와의 혼동을 피한다.
- `app/components/TransitGuide.test.tsx`: 9개 언어 × 부산·대구의 공식 링크·지역 이름·자리표시자·수도권 결과 혼입 여부를 확인하는 회귀 검사 1개. 서버 액션은 호출하지 않는다.

새 의존성, DB 스키마, 예약·발송 상태, 공항 정보, 택시 계산식, WEB/서버 키 경계는 바꾸지 않았다. 부산·대구 선택으로 ODsay를 호출하지 않는다. 지하철 지도 선택은 여행 보드의 방문 도시를 바꾸지 않는 화면 선택이다.

## 과제 요건과 시연

제2강 원문 82쪽의 C 요건은 업무용 AI Agent와 AI 적용 전/후 Workflow 비교다. 지도·티머니 안내는 여행 준비를 돕는 기능이며 이 비교를 대체하지 않는다. G의 VectorDB 조건을 C의 필수 요구로 추가하지 않는다.

발표 흐름은 가상 여행 보드 확인 → 공항·교통 준비 안내 → 늦은 체크인 목표 입력 → 보드 재사용·한국어 초안·역번역 → 승인 후 모의 발송 → 조건부 회신의 조건·기한 이해 → 다음 행동 결정으로 둔다. 지역 안내는 짧게 보여주고 핵심 에이전트 루프에 시간을 쓴다. 아직 수행하지 않은 조건을 완료로 만들지 않는다.

제출 전 남은 검증은 실제 사용자 전후 관찰, 영어 시연 3회 리허설, 운영 요금·외부 링크 확인이다. 이번 UI 검사만으로 R-1 전체·최종 과제 완료 또는 완벽한 에이전트라고 판정하지 않는다.
