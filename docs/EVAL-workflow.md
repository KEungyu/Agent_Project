# AI 적용 전/후 Workflow 비교 — 측정 방법과 관찰 기록 양식

작성 2026-10-06, 비교 절차 보완 2026-10-07. **이 문서에 수집된 실측 결과는 아직 0건이다.** 아래 양식은 비어 있으며, 참여자 관찰 전에는 결과를 채우지 않는다.

사용자 실험은 **2026-10-07 진행 예정**이다(제작자 전달). 실험 후 실제 관찰값을 아래 양식에 기록한다. 실험 예정과 실측 완료를 구분한다.

## 1. 과업 (전후 동일)

늦은 체크인 문의 1건. 전후 모두 같은 가상 예약·같은 회신·같은 완료 기준을 쓴다.

| 항목 | 값 |
|---|---|
| 가상 예약 | Review Test Hotel (fictional) · REVIEW-ONLY · Test Guest · hotel@example.com |
| 일정 | 체크인 2026-10-09, 체크아웃 2026-10-11, 호텔 도착 2026-10-10 01:00 KST |
| 회신 (가상) | "2026년 10월 9일 22시까지 온라인 체크인을 완료하시면 10월 10일 새벽 1시 입실 가능합니다." (조건부) |
| 발송 | 전후 모두 **모의 발송**. 실제 메일을 보내지 않는다 (example.com 포함) |
| 완료 기준 | 요청문을 한국어로 보냄(모의) → 회신을 읽고 조건을 이해함 → 조건에 대한 다음 행동을 정함 |

완료는 "이 문의가 해결됨"이지 새 예약이나 실제 투숙 완료가 아니다. 조건 동의와 조건 이행은 다르다(앱에서도 "요청한 조건을 마쳤어요" 확인으로만 완료).

## 2. Workflow

| 단계 | AI 적용 전 | AI 적용 후 (마중) | 공통 확인 기준 |
|---|---|---|---|
| 자료 준비 | 예약 정보에서 연락처·예약번호 찾기 | 가상 예약 정보를 제공하고 보드 확인 | 같은 가상 자료, 준비 시간 포함 |
| 조건 확인 | 날짜·호텔 도착·연락 방법 직접 정리 | 보드 조회 후 빠진 정보에만 답변 | 착륙과 호텔 도착을 구분 |
| 요청 작성 | 허용된 일반 번역 도구에서 번역·역번역하고 메일 초안에 직접 옮김 | 한국어 초안과 역번역 확인·수정 | 같은 사실·수신처, 사용한 도구 기록 |
| 발송 | 메일 초안을 저장하고 관찰자에게 보여주면 모의 발송으로 기록 (발송 버튼은 누르지 않음) | 이용자 승인 후 앱의 모의 발송 | 실제 업체 발송 0회, 모의 발송 확인 직후 같은 회신 제공 |
| 회신 확인 | 같은 가상 회신을 직접 번역·해석 | 같은 회신을 붙여넣고 분류·조건 확인 | 온라인 체크인 조건과 22시 기한을 이해 |
| 다음 행동 | 이행할 일·기한을 정리 | 조건부 유지 또는 후속 답장 선택 | 조건 동의와 이행을 구분 |
| 문의 해결 표시 | 실제 이행 여부를 따로 확인 | 최신 회신의 이행·기한을 각각 확인해야 완료 | 수행하지 않은 조건은 완료로 표시하지 않음 |

이번 비교 과업의 종료는 “다음 행동을 정확히 정함”이다. 앱 요청 상태 `done`, 새 예약 확정, 실제 투숙과는 다르다. 가상 온라인 체크인·결제를 수행한 것처럼 기록하지 않는다.

적용 전은 **마중이 통합 에이전트 없이 기존 도구를 수동으로 사용하는 절차**다. 일반 번역 서비스도 AI를 쓸 수 있으므로 이를 “AI를 전혀 쓰지 않은 집단”으로 발표하지 않는다. 사용할 번역·메일 도구와 번역 도움 허용 범위를 실험 전에 고정하고 참여자마다 같게 한다. 적용 후 외부 도구를 추가 사용하면 그 시간과 전환도 기록한다. 두 조건 모두 위 예약표에서 시작하며 적용 후에만 보드를 미리 채워 시간을 제외하지 않는다.

## 4. 진행 규칙

- 참여자 4~5명은 **팀 계획**이다. 순서 효과를 줄이려고 절반은 전→후, 절반은 후→전 순서로 한다.
- 소수 표본이라 일반화하지 않는다. 평균과 함께 개별 값을 모두 보여 준다.
- 예상치(58분·7분)와 실측을 섞어 절감률을 내지 않는다.
- 시작 전에는 조작 방법만 안내한다. 진행 중 뜻·다음 행동을 알려줬으면 시점·내용·소요 시간을 적고 도움 없이 성공한 것으로 세지 않는다.
- 조건부 회신 뒤 “무엇을 언제까지 해야 하나요?”, “현재 예약·문의는 어떤 상태인가요?”를 같은 문구로 묻는다. 10/9 22시까지 온라인 체크인이 필요하고, 아직 이행하지 않았다는 뜻을 이해했는지 관찰한다. 유도 답변을 주지 않는다.
- 모의 발송, 외부 사이트 열기, 예약 확정, 조건 동의·이행을 구분하는지 확인한다. 막힌 단계·추가 설명·반복 입력을 기록하고 만족도는 실제 참여자의 답만 쓴다.
- 시연·실험에서는 가상 자료만 쓰고 연락·예약·결제를 실행하지 않는다. 음성·원어민·실기기 검토는 자동 검사와 따로 기록한다.
